Composer studio

Everything else on this site is batch-and-bake: each model composed once, alone, and we analyzed what came out. The studio is the live counterpart — a chat room where a human composer works with the models in real time. Describe a mood or a form and the model composes it; react to what you hear and it revises. The score engraves and the audio renders beside the conversation, every revision stays on a version timeline, and the collaborator controls two experimental knobs per message: the writing method (music21 code vs. ABC notation — the same two modes as the batch study) and which frontier model is doing the composing, switchable mid-conversation.

Sessions are logged in full — prompts, revisions, model reasoning, and every generated score — and feed back into the research: an expert's bar-level reactions are labels no automated judge can produce.
